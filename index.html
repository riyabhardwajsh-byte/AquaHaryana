Premium Android Capabilities Built-In

AquaHaryana combines real-time data integrations, intelligent caching architectures, and local AI companions.

Live Haryana Weather

Fetches current humidity and temperature data for Haryana dynamically using the Open-Meteo REST API. Provides dynamic context warnings directly alongside your daily conservation suggestions.

Local Room Cache

Integrated with a robust SQLite Room Database engine. Caches more than 15 water-saving techniques so you can study, view, and mark favorites even when entirely disconnected in rural areas.

AquaBot Voice Assistant

Features full integration with Gemini API models. Supports speech-to-text input so farmers and community organizers can ask conservation questions using their microphone directly.

Why did Vercel show 404?

AquaHaryana is a **Native Android Application** coded in Kotlin and compiled using Gradle. Standard cloud hosting networks like Vercel expect traditional web applications (such as Next.js, React, or standard HTML sites) and cannot directly compile or run mobile Android Gradle configurations.

To resolve the 404 error, we have added this custom **HTML5 Landing and Documentation Page** to the root of your workspace! Vercel will now automatically build and serve this beautiful landing page, showcasing your app to anyone visiting your domain.

How to Run & Install your Android App

Follow these straightforward steps to experience your completed Native App in real-time.

1

In-Browser Android Streaming Emulator

The absolute fastest way to view your changes is within the **AI Studio browser workspace**. Simply look at the interactive mobile preview streaming interface on the right panel to test and inspect all UI flow changes!

2

Download or Export Android Package (APK/AAB)

Ready to run on physical devices? Click on the **Settings/Menu icon** in the top right-hand area of Google AI Studio. From there, you can export the workspace as a **ZIP package**, push to **GitHub**, or trigger a final build task to export **APKs / AABs** for manual installation on your smartphone.

3

Vercel Web Hosting Deployment

Since you linked your workspace repository with Vercel, this showcase page is now fully live! Vercel will compile and host this elegant landing page seamlessly. No more 404 errors. Anyone clicking your Vercel URL can read your dashboard overview, inspect the offline database capabilities, and download instructions for the APK.
